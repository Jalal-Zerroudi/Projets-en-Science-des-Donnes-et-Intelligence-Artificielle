# Analyse de sentiments sur Twitter

> **État actuel : projet planifié, non implémenté dans ce dépôt.**

## Objectif

Classer des textes courts en sentiments positif, négatif ou neutre à l'aide d'un pipeline NLP reproductible.

## Contenu disponible

Ce dossier ne contient actuellement ni code source, ni notebook, ni corpus, ni modèle entraîné. Les technologies et performances mentionnées dans le [README principal](../README.md) sont des pistes de travail, pas des résultats vérifiés.

## Livrables attendus

- source du corpus et conditions d'utilisation documentées ;
- nettoyage du texte et gestion explicite des langues, URLs et mentions ;
- séparation stratifiée entraînement, validation et test ;
- baseline majoritaire et baseline TF-IDF ;
- fichier de dépendances avec versions ;
- évaluation avec accuracy, F1 macro et matrice de confusion ;
- exemples d'erreurs et limites liées aux biais du corpus.
