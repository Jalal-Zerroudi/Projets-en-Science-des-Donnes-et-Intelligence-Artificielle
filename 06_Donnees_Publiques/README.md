> **État actuel : projet planifié, non implémenté dans ce dépôt.**

## Objectif

Construire un pipeline traçable de préparation, contrôle qualité et visualisation d'un jeu de données public.

Ce dossier ne contient actuellement ni code, ni données, ni rapport, ni tableau de bord. La description du [README principal](../README.md) présente l'orientation envisagée.

- visualisations accompagnées de leurs hypothèses et limites ;
